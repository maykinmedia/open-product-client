Open Product Client
===================

|build-status| |coverage| |python-versions| |pypi-version|

Open product client offers an easy way to communicate with the Open Product APIs.

Features
--------

* Access the available endpoints via the client
* Type safe resources
* Validation of the incoming data via `msgspec <https://msgspec.dev/>`_
